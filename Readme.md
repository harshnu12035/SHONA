### 🛠 Manual Railway Setup

#### Step 1: Create Project
- Go to https://railway.app
- Login with GitHub
- Click **New Project**
- Select **Deploy from GitHub Repo**
- Choose `AnnieXMusic`

---

#### Step 2: Add Environment Variables

Go to **Railway → Variables** and add:

```env
API_ID=
API_HASH=
BOT_TOKEN=
OWNER_ID=
LOGGER_ID=
STRING_SESSION=
MONGO_DB_URI=
